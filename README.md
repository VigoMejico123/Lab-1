# Lab-1


  I wanted to make something that included all of the elements from the project and something that I liked. I knew I wanted to have something to do with skateboarding so first I found the frog on the skateboard and the lamb on the skateboard and added them. Then I had to create a background that made sense with those characters. I tried to make it look like the frog was going down a big hill on the street, and I made the lamb look like it is ollieing off the curb. I liked how it looked but it looked incomplete. I added some rocks/pebbles in front of the frog going down the hill, because it gives an obstacle that he has to dodge if we were to build a video game off of this. Then I added some dust behind the frog to add some motion because it looked too still. Godot was challenging at times, I would loose the pebbles under the background and have trouble getting them back to the top layer. Also I forgot to name all the files at first so it was hard for me to find things, I renamed everything, I wont make that mistake again. It was also difficult to find photos with no backgrounds online, even if I searched PNG it would still have a background, I need to use some software to remove backgrounds in the future. It was also a bit difficult to figure out how to export the Godot file into a format that I could add to Github.
